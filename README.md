## 🚀 Quick Start

### Installation
```bash
# Clone the repository
git clone https://github.com/reeazmahmud/Terminator.git
cd Terminator

# Install dependencies
pip install -e .

# Or install with development dependencies
pip install -e ".[dev]"
```

### Launch Systems
```bash
# Launch with full capabilities
terminator

# Launch specific systems
terminator-sentient --evolve
terminator-discovery --scan
terminator-adapter --connect claude
terminator-ultimate --integrate all
```
